Cross-Model Ensemble — GPT-5.5 + Kimi-K2.6

两个独立模型作为不同 Agent，并行审核后通过确定性融合引擎合并结果

Agent + Harness

Agent 化设计 + Harness 编排

  • GPT-5.5 Agent（主审）Skill: jm-audit-full/light
  • Kimi-K2.6 Agent（复审）Skill: jm-audit-kimi-compact
  • 每个 Agent 拥有独立 Prompt + Tool 权限
  • HARNESS 容错降级协议
  • ✓ GPT OK + Kimi OK → 完整融合
  • ➜ GPT OK + Kimi Fail → 降级 GPT 单模型
  • ➜ GPT Fail + Kimi OK → 降级 Kimi 单模型
  • ✗ Both Fail → 任务失败
  • 每次失败自动记录 error_type + retriable

融合引擎核心算法

Fusion Engine — Deterministic Rule-Based Merging

不依赖第三方仲裁模型，所有融合在本地通过 IoU + 文本相似度 完成，阈值 0.65

匹配算法

问题匹配 _issue_match_score

  • 步骤 1 — 冲突阻断
  • 位置冲突（左上 vs 右下）→ 得分 0
  • 分类冲突（颜色 vs 间距）→ 得分 0
  • 步骤 2 — bbox IoU 匹配
  • IoU ≥ 0.2 → 继续匹配
  • 得分 = 0.75 + 对象相似度(≤0.2) + 语义相似度(≤0.05)
  • 步骤 3 — 无 bbox 文本匹配
  • 最长公共子串 ≥ 4 字符 → 锚点分
  • 文本相似度 ≥ 0.18 → 语义分
  • 综合 ≥ 0.65 → 视为同一问题
融合策略

问题融合 _merge_issue_into

  • ▸ 严重度取高：中 + 高 → 高
  • 确保高风险不被低估
  • ▸ Bbox 取面积小：100×50 vs 60×30 → 选 60×30
  • 定位越精准越好
  • ▸ 文本取长：4 字 vs 24 字 → 选详细版本
  • ▸ Agreement 标签：
  • both / gpt_only / kimi_only / promoted_candidate
# audit_merge.py — 问题匹配核心 def _issue_match_score(left, right): # 冲突阻断 if _side_conflict(left, right): return 0.0 # 左上 vs 右下 if _issue_kind_conflict(left, right): return 0.0 # 颜色 vs 间距 left_bbox = _bbox(left.get('bbox')) right_bbox = _bbox(right.get('bbox')) # 有 bbox → IoU 匹配 if left_bbox and right_bbox: if not _bbox_related(left_bbox, right_bbox): return 0.0 # IoU < 0.2 score = (0.75 + min(object_score, 0.2) + min(semantic_score, 0.05)) return score # 无 bbox → 文本语义匹配 if anchor_score >= 0.6 and object_score >= 0.18: return 0.8 + min(object_score, 0.15) if object_score >= 0.3 and (category_match or semantic_score >= 0.12): return 0.72 + min(semantic_score, 0.08) return 0.0
# audit_merge.py — 融合策略 def _merge_issue_into(target, source): # 严重度取高 target['severity'] = _higher_severity( target.get('severity'), source.get('severity')) # bbox 取面积小 target['bbox'] = _choose_bbox( target.get('bbox'), source.get('bbox')) # 文本字段取长 FIELDS = ['current_observation', 'spec_expectation', 'recommendation', 'location'] for field in FIELDS: target[field] = _longer_text( target.get(field), source.get(field)) for key, value in source.items(): if key not in target and key != '_source_models': target[key] = value

支撑系统的可扩展性、容错性和可维护性

收缩式编排 所有流水线阶段同线程完成，数据流清晰、失败回滚简单

三级容错降级 模型级（错误分类）+ 融合级（单模型降级）+ 图片级（try/except）
三级证据链 Level 1 AI 发现 → Level 2 规则验证 → Level 3 人工复核
控制/数据面分离 SQLite 控制面（几十行记录）+ 文件系统数据面（制品仓库）
